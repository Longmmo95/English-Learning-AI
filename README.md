# English Learning AI

An independent, Vietnamese-first English learning platform for beginners (A1), with a roadmap toward real AI pronunciation assessment at word level.

## Project safety
- This repository is separate from the existing `hoc-tieng-anh` website.
- No files in the existing website are modified by this project.
- Pronunciation scores will only be shown after a real assessment engine is integrated; the app will not generate fake scores.

## Roadmap
1. Responsive learning dashboard and beginner lessons.
2. Vocabulary practice, listening, speaking, and review.
3. FastAPI backend for lessons and learning progress.
4. Open-source speech recognition and word-level pronunciation alignment/scoring.

## Current status
The initial project setup is being built. Word-level pronunciation scoring is not yet available.
